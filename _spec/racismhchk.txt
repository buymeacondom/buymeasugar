## 6. FILE CHECK FLOW
1. User uploads `.txt` file
2. Bot detects → "CARDS LOADED" message
3. Asks: `/yes` (show approved) or `/no` (hide approved)
4. Checks proxy → If none, asks to add
5. "Starting Check" → "Proxy Check Done"
6. "Live Checking" with progress bar + live stats
7. "Check Finished" with final summary
8. User can `/stop` anytime to halt mid-check

## 7. SYSTEM FEATURES

### 7.1 Maintenance Mode
- `/imaintain <reason>` = global pause, stops all active sessions
- `/cmaintain` = resume operations
- Paused sessions show progress and allow re-upload

### 7.2 Credits System
- `/ckey <users> <credits>` = Credits-only key (extra checks beyond role limit)
- `/pkey <users> <days> <credits>` = Premium + Credits key
- `/redeem <key>` = Redeem key
- Logic: Credits = extra checks ON TOP of role limit. Example: Free (300) + 5000 credits = 5300 total checks.

### 7.3 Proxy System
- `/proxy`, `/myproxy`, `/rmproxy`
- Mandatory before checks. Bot verifies proxies before starting.
- No proxy = stop and ask user to add.

### 7.4 SK Checker
- Uses `sk.py` module (adapted from X D channel)
- Commands: `/skcvv`, `/mskcvv`, `/sktxt`, `/skadd`
- `/skadd` validates key + auto test charge
- Returns: charged, live, declined, error
- If `sk.py` missing, return "Stripe SK module not available"

### 7.5 Gateway Lookup
- `/gate` command: auto scan URLs from uploaded `.txt`
- Filter: Only no-captcha, no-cloudflare sites
- Uses `gate.py` module

### 7.6 Logs & Notifications
- Charged/Approved cards → PIN in user chat + forward to Monitor Group + Approved Group + Channel notification
- Declined → user chat only

### 7.7 Anti-Spam
- Auto-ban >20 events in 10s window
- Rate limit: 20s cooldown per user for `/sc`, `/msc`, `/br`
- ThreadPool: 500 workers, Semaphore: 100 per user for mass checks
