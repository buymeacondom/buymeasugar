7.2 Critical Debugging Notes
If bot receives updates but sends no reply (Duration 0 ms):
1. Check auth.py has get_user_role() method inside UserAuth class.
2. Check .env has valid BOT_TOKEN (not revoked).
3. Check bot is admin in channel/group (for join check).
4. If premium emojis fail, bot falls back to standard emojis or plain text.
5. Use python -B bot.py to avoid pycache permission issues.
7.3 Token Security Rules
NEVER share token in chat — Telegram auto-revokes it.
NEVER commit .env to GitHub — add .env to .gitignore.
Always use os.environ.get("BOT_TOKEN") in bot.py.
